# Rapport LaTeX — importation Overleaf

1. Compresser le contenu de ce dossier en ZIP, ou utiliser l'archive fournie à la racine du projet.
2. Dans Overleaf, choisir **New Project > Upload Project** puis sélectionner le ZIP.
3. Ouvrir `main.tex`, qui est le point d'entrée unique.
4. Choisir le compilateur **pdfLaTeX**. Si la bibliographie n'est pas générée automatiquement, choisir le workflow **LaTeX + Biber** proposé par Overleaf.
5. Compiler deux fois si nécessaire afin d'actualiser le sommaire, les listes, les références croisées et la bibliographie.
6. Les logos de l'Université Mohammed V et de l'ENSAM Rabat sont déjà intégrés dans `figures/` et dans la page de garde.
7. L'année universitaire indiquée dans le rapport est `2026/2027`.

Le rapport utilise des chemins relatifs : les chapitres sont dans `chapters/`, les annexes dans `appendices/` et les figures dans `figures/`. Le contenu scientifique et les résultats proviennent des fichiers réels du projet ; aucun résultat n'a été ajouté artificiellement.
